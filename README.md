# 🤖 Telegram Support AI Bot

Асинхронный Telegram-бот на базе **aiogram 3** и **OpenRouter API** для автоматизации первой линии клиентской поддержки и консультаций.

---

## 🚀 Ключевые особенности

- **Отказоустойчивая архитектура (Fallback Pool):** автоматический перебор пула нейросетевых моделей при возникновении ошибок `429 (Rate Limit)` или временной недоступности инстанса, что гарантирует высокий аптайм без падения бота.
- **Полная асинхронность:** проект построен на базе `aiogram` и асинхронного клиента API, обеспечивая быструю обработку параллельных сообщений пользователей.
- **Изолированная конфигурация:** системные роли, токены и поведение вынесены в переменные окружения (`.env`) и `config.py`. Бот мгновенно адаптируется под любой сценарий (e-commerce, техподдержка, кастомные ролевые задачи) изменением системного промпта.
- **Безопасность:** строгая изоляция токенов и секретных ключей через `.gitignore`.

---

## 🛠 Стек технологий

- **Python 3.11+**
- **aiogram 3.x** (Telegram Bot API)
- **OpenAI Python SDK** (AsyncOpenAI client)
- **OpenRouter API** (Open-source LLM: Nemotron, Qwen, Liquid)
- **python-dotenv**
